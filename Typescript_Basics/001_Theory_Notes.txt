*****************************************  Symbol() ************************************************************

Symbol is basically a data type in TypeScript it basically makes sure that the key we are making for object
data type should be unique and should not be duplicated in future below see example

suppose multiple people are working in single object ids

Symbol is a primitive data type in TypeScript/JavaScript. It is used to create unique identifiers.
    The main purpose of Symbol is to create object property keys that are guaranteed to be unique, helping
    avoid accidental property name collisions.

Without Symbol:
const ids = {user_1 : 1, user_2: 2};

Another developer may accidentally use the same key:
ids.user_1 = 3;

Now the original value is overwritten. To avoid property name collisions, we can use Symbol.

const user = Symbol("user_1");       // think like unique id is xyz for user_1

const ids = {[user]: 1, user_2: 2};

The property key is now a unique Symbol instead of the string "user_1".

Even if another developer creates:
const anotherUser = Symbol("user_1");   // think like unique id is abc for user_1

both Symbols are different.
console.log(user === anotherUser);

Output:
false

Therefore, Symbol keys are unique and do not conflict with other property names.

***********************  Nullish Coalescing (??)

Basically if the null value present, and you want to override only null value then we can use this approach

let user = null;
console.log(user?? "Guest")   >> Guest

let user = "Shashank";
console.log(user?? "Guest")   >> Shashank

********************************************   Enum   *****************************************************
Enum basically decide what values can be assign to variable it save us to enter wrong values and typo errors

Below example is there for numeric enums

enum Status {Pass, Fail, Skip}

let result: Status = Status.Pass;           // correct because Pass is present inside enum
let result: Status = Status.Pas;           // fail show error because Pas is a typo error
let result: Status = Status.Fail;           // correct because Fail is present inside enum
let result: Status = Status.Failure;           // fail show error because Failure is not defined inside enum
console.log(Status.Pass);                  // 0

to get all the values and keys of enum we can write like >>>  console.log(Status);

also give the default values like (indexing)
Pass = 0
Fail = 1
Skip = 2

but if you want to change order you can give like
enum Status {Pass=1, Fail, Skip}

so now default values be like
Pass = 1
Fail = 2
Skip = 3

Below example is there for string enums
enum CardinalDirections {North = 'North', East = "East", South = "South", West = "West"};

Note:: for string enum it won't do indexing

In modern way in place of enum we use union type example is given below
type Status = "Pass" | "Fail" | "Skip";
let result = Status.Pass                  >>> Assign Pass inside result

Note::  the main difference is enum creates object and  do internal indexing like 0, 1, 2 but union type don't do
and also enums can be used by there names but for union type it is not required

**************************************** data type identification  ************************************

In TypeScript there is NO method to identify the datatype on characters which is given inside string
 in python we have methods like isdigit() isnum() isalpha() or isalnum() but here there is no such type
 of methods so the easiest way to find out the difference between number, alphabets and special character is
 regex so if we have problem like "Shashank09@#$%" and we need to identify then we can use below trick
 /[0-9]/.test("value")             >>>>>>>  this is to check digit value, can be anything
 /[A-Z]/.test("value")             >>>>>>>  this is to check capital alphabets, value can be anything
 /[a-z]/.test("value")             >>>>>>>  this is to check small alphabets, value can be anything
 /[^a-zA-Z0-9]/.test("value")      >>>>>>>  this is to check special character, value can be anything

Note:: ^ is a negation sign it will neglect the given pattern and only look for the other values and .test
 is a part of regex which is use the check the value we can consider as a syntax of regex

Note:: see below the meaning of signs if we write these outside of [] and inside of \\ like \^[]+$\

^ = start of string
$ = end of string
+ = one or more times  (check below examples for better understanding)

So if we have scenario to allow only numbers either single digit or multiple digit then we can write regex like below
/^[0-9]+$/  >>> this will allow only for numbers either one or multiple digit like (1, 9999 or 23)

/^[0-9]$/  >>> this will allow only for numbers but only one digit like (1, 4 or 9) if we put 99 then throw error

 ****************************************   handling spaces    ********************************************

 To handle spaces in TypeScript we use trim method or replace method with replace method we can use regex

>> when we have scenario in which we have to handle (space, tab and next line) the go for regex below given with replace method
  /\s/g   >>>>>>>>   this \s is for matching pattern (space, tab and next line) and g means global

>> when we have scenario in which we have to handle only spaces the go for trim method below given with replace method
trim()                 // Remove spaces from start and end
trimStart()            // Remove spaces from start
trimEnd()              // Remove spaces from end
replaceAll(" ", "")    // Remove all normal spaces
replaceAll(/\s/g, "")  // Remove all (whitespace , tab, nextline)
replace(" ", "")       // Remove only first space
